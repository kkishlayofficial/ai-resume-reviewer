# AI Resume Reviewer

An end-to-end AI-powered resume evaluation tool. Upload your resume, paste a job description, and receive a structured analysis — including ATS alignment, technical depth, communication quality, strengths, weaknesses, missing keywords, prioritised recommendations, and a job fit verdict — all generated by a Groq-hosted LLM with structured output.

The result can be downloaded as a formatted PDF report.

---

## How It Works

The application follows a 3-step wizard:

```
Step 1 — Upload
  └── User uploads a PDF or DOCX resume
  └── Backend extracts text and validates it is actually a resume (LLM check)
  └── Extraction warnings are surfaced to the user

Step 2 — Verify
  └── User reviews and optionally edits the extracted text
  └── User pastes a job description and selects their experience level
  └── User triggers the AI review

Step 3 — Dashboard
  └── Scores (Overall, ATS, Technical, Communication) with reasoning
  └── Skills, Strengths, Weaknesses, Missing Keywords
  └── Prioritised recommendations (High / Medium / Low)
  └── Job fit verdict with explanation
  └── Download as a PDF report
```

All state (extracted text, review result, uploaded file) is persisted to `localStorage` — a page refresh does not lose progress.

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 20+
- A [Groq API key](https://console.groq.com)

---

### Backend

```bash
cd backend

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env with your Groq API key
echo "GROQ_API_KEY=your_key_here" > .env

# Start the server
uvicorn main:app --reload
```

The API runs at `http://localhost:8000`.

---

### Frontend

```bash
cd frontend

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app runs at `http://localhost:5173`.

> **Mock mode:** `src/services/resumeApi.ts` has a `MOCK_MODE = true` flag. When enabled, all API calls return hardcoded sample data with simulated delays — useful for UI development without a running backend. Set it to `false` to use the real backend.

## Scoring Formula

The overall score is a weighted average of three LLM-evaluated dimensions:

| Dimension | Weight | What it measures |
|---|---|---|
| Technical | 50% | Technologies, tools, frameworks, and experience explicitly in the resume |
| ATS | 30% | Keyword and qualification alignment with the job description |
| Communication | 20% | Clarity, structure, and quantified achievements in the resume |

All scores are integers from 0–100. The LLM evaluates against the selected experience level (Junior / Mid-Level / Senior).

## API Overview

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/resume/extract` | Upload PDF/DOCX → extract text + LLM resume validation |
| `POST` | `/resume/review` | Submit resume text + JD + level → structured AI evaluation |
| `POST` | `/resume/report` | Submit review result → download PDF report |
| `GET` | `/resume/experience-level` | List valid experience level values |

## Key Features

- **LLM resume validation** — the extraction step uses a second LLM call to confirm the uploaded file is actually a resume before proceeding
- **Editable extracted text** — users can correct OCR/formatting errors before analysis
- **Extraction warnings** — backend warnings are surfaced as a banner in Step 2
- **Session persistence** — full state including the uploaded file is saved to `localStorage`; picking a new file resets all prior progress
- **PDF report** — a formatted ReportLab-generated report covering all evaluation dimensions, downloadable directly from the dashboard
- **Dark mode** — theme persisted to `localStorage`, falls back to OS preference
- **Mock mode** — develop the full UI without a backend

---

## Known Limitations

- No image resume support (no OCR) — PDF and DOCX only
- Scanned PDFs (image-embedded) return empty text and fail validation
- No authentication or rate limiting at the application level
- Groq free tier has strict TPM limits — large resumes with long job descriptions may hit rate limit errors
- No session history — only the current session is stored
