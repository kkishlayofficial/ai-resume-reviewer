# AI Resume Reviewer

An end-to-end AI-powered resume evaluation tool. Upload your resume, paste a job description, and receive a structured analysis — including ATS alignment, technical depth, communication quality, strengths, weaknesses, missing keywords, actionable patch-based improvements, and a job fit verdict — all generated by a Groq-hosted LLM with structured output.

Each improvement can be applied directly to your resume with a single click. After applying improvements, re-evaluate your resume to see the updated score — the app tracks every change and shows you exactly how much each improvement raised your score.

The result can be downloaded as a formatted PDF report.

---

## How It Works

The application follows a 3-step wizard:

```
Step 1 — Upload
  └── User uploads a PDF or DOCX resume
  └── Backend extracts text and validates it is actually a resume (LLM check)
  └── Extraction warnings are surfaced to the user

Step 2 — Verify
  └── User reviews and optionally edits the extracted text
  └── Newly applied improvements are highlighted in green
  └── User pastes a job description and selects their experience level
  └── User triggers the AI review

Step 3 — Dashboard
  └── Scores (Overall, ATS, Technical, Communication) with reasoning
  └── Score deltas shown after re-evaluation (e.g. 78 → 91  +13)
  └── Skills, Strengths, Weaknesses, Missing Keywords
  └── Actionable Improvements — patch-based cards with + Add to Resume buttons
  └── Applied counter (Applied: 2/3) and Re-evaluate Resume button
  └── Job fit verdict with explanation
  └── Download as a PDF report
```

All state (extracted text, review result, uploaded file, applied improvements) is persisted to `localStorage` — a page refresh does not lose progress.

---

## Actionable Improvements

Unlike traditional recommendation lists, every improvement card in Step 3 tells the AI exactly what to add and where:

| Field | Description |
|---|---|
| `section` | Which resume section the change applies to (`summary`, `experience`, `skills`, `projects`, `education`) |
| `action` | How to apply it — `append` or `insert` (auto-applied) / `replace` (manual suggestion) |
| `suggested_content` | The exact text to insert |
| `reasoning` | Why this change matters for the target role |

Clicking **+ Add to Resume** on an `append`/`insert` card:
1. Patches the resume text at the correct section boundary
2. Highlights the inserted content in green in the Step 2 editor
3. Marks the card as ✓ Applied

`replace`-type cards (suggested rewrites of existing bullets) show a before/after suggestion and prompt the user to update manually in Step 2 — avoiding accidental data loss from automated overwrites.

After applying improvements, clicking **Re-evaluate Resume** sends the updated resume text to the AI and returns a new score. The original baseline score is preserved so the improvement delta is always visible.

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 20+
- A [Groq API key](https://console.groq.com)

---

### Backend

```bash
cd backend

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Copy the example env file and fill in your key
cp .env.example .env
# Edit .env and set GROQ_API_KEY

# Start the server
uvicorn main:app --reload
```

The API runs at `http://localhost:8000`.

---

### Frontend

```bash
cd frontend

# Install dependencies
npm install

# Copy the example env file (default points to localhost:8000)
cp .env.example .env

# Start the dev server
npm run dev
```

The app runs at `http://localhost:5173`.

> **Mock mode:** `src/services/resumeApi.ts` has a `MOCK_MODE = true` flag. When enabled, all API calls return hardcoded sample data with simulated delays — useful for UI development without a running backend. Set it to `false` to use the real backend.

## Deployment

Both services are deployed separately on Vercel.

| Service | Live URL |
|---|---|
| Frontend | https://ai-resume-reviewer-rho-rust.vercel.app |
| Backend | https://ai-resume-reviewer-be.vercel.app |

### Deploy the backend

1. Import the repo into a new Vercel project → set **Root Directory** to `backend`
2. Vercel detects `vercel.json` automatically and uses `@vercel/python`
3. Add environment variables in project settings:
   ```
   GROQ_API_KEY     = your_groq_api_key
   ALLOWED_ORIGINS  = https://your-frontend.vercel.app
   ```
4. Deploy

### Deploy the frontend

1. Import the repo into a separate Vercel project → set **Root Directory** to `frontend`
2. Framework preset: **Vite**
3. Add environment variable:
   ```
   VITE_API_BASE_URL = https://your-backend.vercel.app
   ```
4. Deploy

> `vercel.json` in both directories handles all routing (`rewrites` for the SPA, and the serverless function entrypoint for the API). No additional Vercel configuration is needed.

## Scoring Formula

The overall score is a weighted average of three LLM-evaluated dimensions:

| Dimension | Weight | What it measures |
|---|---|---|
| Technical | 50% | Technologies, tools, frameworks, and experience explicitly in the resume |
| ATS | 30% | Keyword and qualification alignment with the job description |
| Communication | 20% | Clarity, structure, and quantified achievements in the resume |

All scores are integers from 0–100. The LLM evaluates against the selected experience level (Junior / Mid-Level / Senior).

## Key Features

- **LLM resume validation** — the extraction step uses a second LLM call to confirm the uploaded file is actually a resume before proceeding
- **Editable extracted text** — users can correct OCR/formatting errors before analysis
- **Patch-based actionable improvements** — each recommendation includes the exact section, action type, and suggested content; `append`/`insert` improvements are applied automatically with one click
- **Green highlight on applied text** — newly inserted content is highlighted in the Step 2 editor via a transparent-textarea overlay technique; highlights clear on manual edits
- **Re-evaluate with score delta** — after applying improvements, re-score the updated resume and see the before → after comparison (`78 → 91  +13`)
- **Applied tracking** — `Applied: N/M` counter and per-card ✓ Applied state; persisted across navigation
- **Extraction warnings** — backend warnings are surfaced as a banner in Step 2
- **Session persistence** — full state including the uploaded file is saved to `localStorage`; picking a new file resets all prior progress
- **PDF report** — a formatted ReportLab-generated report covering all evaluation dimensions, downloadable directly from the dashboard
- **Dark mode** — theme persisted to `localStorage`, falls back to OS preference
- **Mock mode** — develop the full UI without a backend

## Known Limitations

- No image resume support (no OCR) — PDF and DOCX only
- Scanned PDFs (image-embedded) return empty text and fail validation
- No authentication or rate limiting at the application level
- Groq free tier has strict TPM limits — large resumes with long job descriptions may hit rate limit errors
- No session history — only the current session is stored
- Text patching relies on section header detection via keyword matching — non-standard section headings may fall back to end-of-document append
- Vercel Python serverless functions have a cold start on first request after inactivity (~1–3s on free tier)
